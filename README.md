# Mohammed Al-Mahjani — Network & Cybersecurity Engineer Portfolio

A professional one-page portfolio website for a Network & Cybersecurity Engineer.
Built with clean, framework-free Vanilla HTML, CSS, and JavaScript.

---

## 🔐 About This Project

This portfolio showcases expertise in:

- Network architecture and design
- Cybersecurity and penetration testing
- Network automation and smart systems (Sam-Smart)
- Hands-on network lab environments
- Professional certifications

## ✅ Planned Features

- **Hero Section** — Full-screen landing with animated typing effect and glitch text
- **About Section** — Profile photo, bio, and quick stats (years of experience, projects, certs)
- **Skills Section** — Animated skill bars grouped by category (Networking, Security, Tools)
- **Projects Section** — Interactive project cards with tech stack tags and links
- **Sam-Smart Showcase** — Dedicated deep-dive section for the Sam-Smart system
- **Network Labs** — Documented hands-on labs with topologies and screenshots
- **Experience Section** — Timeline of professional experience
- **Certificates Section** — Certification cards with verify links and badge images
- **Contact Section** — Contact form with validation + social media links
- **Scroll Animations** — Smooth reveal animations triggered by IntersectionObserver
- **Particle Background** — Canvas-based floating particle effect in the hero section
- **Mobile Responsive** — Fully responsive across all screen sizes (mobile-first)
- **Dark Cyber Theme** — Premium dark aesthetic with cyan/green glow accents
